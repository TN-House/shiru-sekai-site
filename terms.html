利用条件

この文書は、知るセカイ YouTube APIの運用範囲を説明するための草案です。公開・適用開始日は未設定であり、現時点で利用契約や法的同意を成立させるものではありません。

対象となるツール

対象は、知るセカイのチャンネル運営者本人が、自分のMac上で利用するPython CLIです。一般向けのアカウント登録、他者のチャンネル運用、第三者への認証情報の提供を行うサービスではありません。説明用ウェブページは、OAuthや動画操作を行いません。

Google・YouTubeの条件

APIを利用する際は、適用される YouTube利用規約、 Google APIの規約、YouTube API Services User Data Policy、各サービスのポリシーに従います。Google OAuthの同意は、動画のアップロード・公開・コメント投稿を自動的に承認するものではありません。

動画編集用の同意スコープは、Google側では動画・評価・コメント・字幕の表示や編集、動画の完全削除を含む広い権限です。CLIに実装されている機能はこの範囲より限定されます。Analyticsは別の読み取り専用認可で、編集用認可と区別されます。詳しいデータの扱いは プライバシーポリシー をご確認ください。

運営者による確認

  • 動画の権利、音源・素材の利用、タイトル・説明、公開対象、公開日時、YouTube上の申告設定は、送信・予約の前に運営者本人が確認します。
  • 動画の予約・メタデータ更新は、対象動画・変更内容・保存状態を確認してから実行します。コード上の検査結果だけで、内容の正しさ、権利の有無、公開可否は保証されません。
  • コメント投稿機能を使う場合、投稿本文と公開先動画を運営者が確認します。投稿されたトップレベルコメントはYouTube上で公開されます。
  • Analyticsの集計値は取得時点・対象期間・YouTubeの集計条件に依存します。視聴者数、収益、動画の成果や審査結果を保証しません。

停止・アクセス取消

運営者はローカル処理を停止し、 Googleアカウントの接続管理 から各OAuthアクセスを取り消せます。Google側のアクセス取消と、Mac上の認証情報・取得ファイル・処理記録の削除は別の操作です。詳細は プライバシーポリシー をご確認ください。認証失効、API制限、通信障害、必要な確認の不足があれば処理を停止する場合があります。
