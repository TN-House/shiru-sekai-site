知るセカイ YouTube API

チャンネル運営者が自分のMacで使う、YouTube動画の状態確認・メタデータ編集・予約設定・読み取り専用の分析を行うローカルツールです。

一般向けのアカウント登録サービスや、他の人のGoogleアカウントを接続するサービスは提供していません。このサイトは内容を説明する静的ページで、GoogleへのログインやYouTube APIアクセスを行いません。

このツールでできること

  • 本人が管理する知るセカイのチャンネルと動画の情報・公開状態を読み取り、対象を照合します。
  • 手動でYouTubeへアップロードした動画について、確認済みのタイトル・概要欄・カテゴリや公開予約を編集します。書き込み前に変更計画を確認し、別の動画への誤送信や不明な結果での自動再送を防ぐ仕組みがあります。
  • 別に許可を得た読み取り専用のAnalytics認可で、チャンネル・動画の集計視聴指標を取得し、Mac上で分析します。
  • 公開動画に対して、内容を確認した質問をチャンネル名義でトップレベルコメントとして投稿するコードがあります。実運用でのコメント投稿はまだ記録されていません。

動画ファイルのYouTubeアップロードや動画削除は、このCLIの機能ではありません。アップロードは運営者が別途YouTubeアプリから行います。

Google権限について

動画編集用のOAuth権限 youtube.force-ssl は、Googleの同意画面上では動画・評価・コメント・字幕の表示、編集、完全削除を含む広い権限として説明されます。このCLIに実装されている動画操作は、情報の読み取り、メタデータ・公開予約の更新、および公開動画のトップレベル質問コメントの読み書きです。動画の削除、評価の変更、字幕の変更は実装していません。

Analytics機能は別の同意で yt-analytics.readonly と youtube.readonly を使用します。編集用の認可に自動で含まれるものではなく、分析結果をYouTubeへ書き戻す機能もありません。
